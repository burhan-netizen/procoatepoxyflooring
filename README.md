# Procoat Epoxy Flooring website

A responsive, static one-page site for Procoat Epoxy Flooring in Townsville, Queensland.

Open index.html in a browser. No build step or package installation is required.

## Quote form

The form validates required fields and opens the visitor's email app with a prefilled message to admin@procoatepoxyflooring.com. It does not send data to a server. Connect it to a form service or backend before relying on it for unattended lead capture.

## Before publishing

- Confirm the business phone, email, service area, Facebook page and copy.
- Replace generated finish visualisations with approved photos of completed Procoat work when available. Current images are clearly labelled as illustrative concepts.
- Replace the clearly marked testimonial placeholders with approved customer quotes, names and locations before publishing. No reviews or customer identities are presented as real.
- Add the final website domain to canonical and Open Graph metadata once selected.
- Connect the quote form to a hosted form handler if email-app submission is not suitable.
